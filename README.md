## Обо мне

Разработчик с практическим интересом к низкоуровневой производительности (C/C++) и скоростной серверной разработке на Python.
Имею опыт построения учебного HTTP-фреймворка с нуля на С++26, а также бэкенда для волонтёрского приложения на Python3.14.
Развиваюсь в сторону TDD, проектирования архитектуры и понимания сетевых протоколов, а также
планирую идти в сторону кибербезопасности.

Продолжительное время работаю на Linux-based дистрибутивах: имею опыт с Ubuntu, Arch Linux, Void Linux и CachyOS. Сейчас использую Void Linux для локального файлового сервера, а CachyOS — на основной машине. Также есть практический опыт конфигурации `nginx` и `ufw`.

## Избранные проекты

### [Polonium](https://github.com/Les-S-niK/Polonium) · `C++`

Учебный HTTP-JSON API-фреймворк, написанный с нуля. Включает парсинг HTTP через `llhttp`, JSON-сериализацию на `glaze` и compile-time регулярные выражения. Собирается через CMake + Conan.

### [VolunteersBackend](https://github.com/Les-S-niK/VolunteersBackend) · `Python / FastAPI`

Бэкенд-часть городского волонтёрского приложения. Реализованы модели данных, обработчики API ( подход REST-API ) и тесты (`tests/api_v1`). Используются FastAPI, SQLAlchemy ORM и современный `pyproject.toml`.
